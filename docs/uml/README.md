# 📐 Diagramas UML (Unified Modeling Language)

A **UML (Linguagem de Modelagem Unificada)** é o padrão internacional da engenharia de software para visualizar, especificar, construir e documentar os artefatos de um sistema orientado a objetos.

Nesta pasta estão os diagramas fundamentais que mapeiam a estrutura estática e o comportamento dinâmico do projeto.

---

## 🗂️ Diagramas Disponíveis

| Diagrama | Tipo UML | Descrição | Arquivo |
| :--- | :--- | :--- | :--- |
| **Diagrama de Classes** | Estrutural | Mostra as classes, interfaces, herança, atributos, métodos e os relacionamentos de dependência do sistema. | [Acessar Diagrama](./diagrama_classes.md) |
| **Diagrama de Casos de Uso** | Comportamental | Mapeia o ator principal (Operador do Sistema) e as operações/funcionalidades que ele executa. | [Acessar Diagrama](./diagrama_casos_de_uso.md) |
| **Diagrama de Sequência** | Interação / Dinâmico | Demonstra a troca de mensagens ao longo do tempo entre as telas, o repositório e os modelos. | [Acessar Diagrama](./diagrama_sequencia.md) |

---

## 💡 Por que a Modelagem UML é Importante?

1. **Comunicação Universal**: Qualquer desenvolvedor no mundo, independentemente da linguagem que fala, consegue ler um diagrama UML e entender a arquitetura do sistema em minutos.
2. **Separação de Abstração e Implementação**: Permite enxergar o design do software antes mesmo de olhar para uma linha de código em C#.
3. **Padrão de Engenharia**: Demonstra maturidade de arquitetura ao criar software com planejamento e rigor técnico.
